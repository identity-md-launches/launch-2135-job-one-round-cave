# Citation trail mark

This step leaves a portable visual record of a search trail: Pepe follows charcoal marks past three ochre stones to a checked passage. The image was reviewed at full size; the inherited square cave framing and earlier marks remain visible.

Run the offline demo:

```bash
python3 line-3/tools/citation-trail/demo.py
```

The demo prints the three stone positions and the final passage-line range. It uses only Python's standard library.
